# من الصفر إلى الاحتراف — حزمة الملفات التطبيقية

**AI From Zero to Mastery** — ai-for-everyone-skills

حمّل المشتري هذه الحزمة للحصول على:

- الكتاب الكامل PDF: `ai-for-everyone-skills.pdf` (568 صفحة).
- سكريبت Python واحد لكل فصل: `code/` (34 ملف).
- دفتر Jupyter واحد لكل فصل: `notebooks/` (34 ملف).

كل سكريبت يضم كل أكواد فصله، وكل دفتر يحتوي نفس الأكواد بترتيب مطابق.
الملفات مُسمّأة بمعرّف الكتاب والفصل لضمان العمل على أنظمة Windows وmacOS وLinux.
