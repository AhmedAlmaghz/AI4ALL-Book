# من الصفر إلى الاحتراف — الذكاء الاصطناعي في حياتك ودراستك وعملك

مشروع كتاب تدريبي عربي لغير المتخصصين، من الصفر إلى الاحتراف، بأسلوب قصصي عملي، مدعوم بالرسوم والمخططات والمقارنات والنصائح والتحذيرات.

> هذا مشروع مستقل عن كتاب «رياضيات الذكاء الاصطناعي» الموجود في المجلد الأعلى. لا تعدّل ملفات ذلك المشروع.

## حالة المشروع

- **الإصدار:** 0.23 — نسخة مراجعة كاملة (مسودة)
- **المرحلة الحالية:** مسودات الفصول 1–34 مكتملة، ونُفّذ تصدير كامل إلى PDF وEPUB 3 وHTML. التحقق الواقعي والتحرير البشري واختبار القراء وفحص الإتاحة ما زالت بوابات مفتوحة.
- **المخطوطة:** 34 فصلًا في 7 أجزاء، 111,253 كلمة بعد استبعاد ملاحظات المؤلف (ضمن هدف 110,000–125,000).
- **الادعاءات:** 257 سجلًا في `docs/fact-check-log.csv`: 74 موثقًا، 89 موثقًا جزئيًا، 18 مثالًا توضيحيًا، 76 توصية تحريرية. أُنشئت قائمة عمل تفصيلية للادعاءات الجزئية في `docs/partial-claims-review.md`.
- **الرسوم:** 67 شكلًا SVG بهوية بصرية واحدة، مولّدة من `scripts/generate-figures.py`، مع تعليق ونص بديل لكل شكل.
- **الخطوط:** ستة خطوط TTF محلية (IBM Plex Sans Arabic وAlexandria وInter وIBM Plex Mono) مضمّنة في PDF وEPUB، بتراخيص OFL.
- **نسخة القراءة:** `dist/book-full-draft.pdf` (568 صفحة A4 ملوّنة)، و`dist/book-full-draft.epub` (EPUB 3، 34 فصلًا في التنقل، 67 رسمًا، 6 خطوط)، و`dist/book-full-draft.html`.
- **الفصل التجريبي:** الفصل 5 — «أول حوار ناجح».
- **المؤلف:** م/أحمد صالح المغز (بانتظار التأكيد).
- **اللغة:** العربية الفصحى المبسطة، اتجاه RTL.

> **ملاحظة الصفحات:** هدف التخطيط الأصلي 450–480 صفحة، لكن التصميم الحالي A4 مع 67 شكلًا كامل العرض و34 افتتاحية فصل ينتج 568 صفحة. الفرق موثق في `docs/export-report.md`، وقرار معالجة الصفحات (ضبط التصميم أو تعديل الهدف) ما زال مفتوحًا قبل الاعتماد النهائي.

## المبادئ الحاكمة

1. القارئ غير المتخصص هو الحَكَم الأول.
2. فكرة واحدة كبيرة في كل فصل.
3. كل فصل ينتج أثرًا ملموسًا، لا مجرد معرفة.
4. القصة تخدم التعلم، ولا تزاحمه.
5. التحقق والأمان جزء من كل مهارة، لا فصل منفصل فقط.
6. الأدوات أمثلة قابلة للتحديث؛ المبادئ هي الثابت.
7. كل عنصر بصري يخدم فهمًا، وله تعليق ومصدر ونص بديل.
8. لا معلومة بلا مصدر، ولا ادعاء بلا تحقق.
9. العربية الفصحى المبسطة، بلا حشو ولا تعقيد.
10. الجودة بوابة، لا رأيًا.

## طريقة العمل

- كل فصل يُكتب في ملف Markdown مستقل ويتبع قالب الفصل.
- كل ادعاء قابل للتحقق يُسجل في `docs/fact-check-log.csv`.
- كل لقطة شاشة تُسجل في `docs/screenshot-register.csv`.
- حالة كل فصل تُحدّث في `docs/curriculum-matrix.csv`.
- لا يُعتبر الفصل مكتملًا حتى يمر ببوابات الجودة في `docs/production-plan.md`.

## بناء الرسوم والتصدير

```powershell
# 1) توليد الأشكال الـ67 من وحدات الرسم
python -X utf8 scripts/generate-figures.py

# 2) (اختياري) معاينة شكل واحد إلى PNG
python -X utf8 scripts/render-svg.py assets/figures/fig-05-1.svg

# 3) تصدير PDF + EPUB + HTML
python -X utf8 scripts/export-book.py
```

**المتطلبات:** Python 3 مع `Markdown` و`lxml` و`PyMuPDF`، وChrome أو Edge لبناء PDF. ينسخ التصدير الخطوط إلى `dist/fonts/` و`EPUB/fonts/`، ويحقن كل شكل داخل `<figure>` مع `<figcaption>` ونص بديل.

المخرجات:

- `dist/book-full-draft.pdf` — نسخة مراجعة A4 ملوّنة، 568 صفحة.
- `dist/book-full-draft.epub` — EPUB 3 قابل لإعادة التدفق، RTL، 34 فصلًا، 67 SVG، 6 خطوط.
- `dist/book-full-draft.html` — نسخة قراءة واحدة بفهرس وروابط داخلية.
- `dist/book.css` — ستايل التصدير بخطوط محلية.

راجع [تقرير التصدير](docs/export-report.md). هذه نسخة مسودة وليست اعتمادًا للطباعة أو النشر.

## فحص الجودة

```powershell
$env:PYTHONIOENCODING="utf-8"
[Console]::OutputEncoding=[System.Text.Encoding]::UTF8
python -X utf8 scripts/check-manuscript.py
```

يفحص الاتساق البنيوي للفصول الـ34، وترقيم الأشكال، وحالات سجل التحقق. بوابة الدقة البشرية تبقى مفتوحة حتى إغلاق الادعاءات الجزئية.

## الخطوات التالية

1. إغلاق ادعاءات P1 (القانون، الخصوصية، الصحة) مع مراجعين مختصين، ثم P2 وP3 وفق `docs/partial-claims-review.md`.
2. حسم قرار الصفحات: ضبط كثافة تصميم A4 للوصول إلى 450–480، أو اعتماد 540–580 صفحة وتحديث هدف التخطيط رسميًا.
3. التحرير اللغوي والتطويري الشامل، ومراجعة الرسوم والنصوص البديلة.
4. اختبار القراءة والتنقل والإتاحة مع قراء من الشرائح المستهدفة، وفحص قارئ الشاشة.
5. اعتماد العنوان واسم المؤلف وبيانات الناشر وISBN، ثم بروفة ورقية واعتماد PDF/X إن لزم.

## ملاحظة حقوق

جميع الحقوق محفوظة للمؤلف. لا تُنشر الصور أو اللقطات أو النصوص دون إذن. تُوثّق تراخيص الخطوط والرسوم في `assets/` و`docs/design-system.md`.
