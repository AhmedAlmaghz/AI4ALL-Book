# خطة الإنتاج — Production Plan

## 1. الهدف

إنتاج كتاب عربي احترافي، من الصفر إلى الاحتراف، في 30–32 أسبوعًا، بجودة قابلة للتحقق، مع نسخة مطبوعة ورقمية وملحقات تدريبية.

## 2. المراحل

| المرحلة | المدة | المخرجات | بوابة الخروج |
|---|---|---|---|
| 0. الاكتشاف والقرارات | أسبوعان | موجز الكتاب، تحليل 7 كتب، 12 مقابلة | G0 |
| 1. المخطط | 3 أسابيع | مصفوفة 34 فصلًا، دستور القصة، دليل الأسلوب، النظام البصري | G1–G2 |
| 2. النموذج التجريبي | 3 أسابيع | 3 فصول + 8 صفحات نموذجية | G3 |
| 3. الإنتاج | 14 أسبوعًا | 31 فصلًا + الرسوم واللقطات | G4–G6 |
| 4. التجميع | 3 أسابيع | مخطوطة كاملة، فهرس، إحالات | G7 |
| 5. المراجعة والاختبار | 3 أسابيع | نسخة بيتا، تدقيق إتاحة، بروفة طباعة | G8 |
| 6. الإطلاق | أسبوعان | PDF/EPUB، دفتر الرحلة، دليل المدرب | G9 |

**الإجمالي:** 30–32 أسبوعًا.

## 3. دفعات الإنتاج

| الدفعة | الفصول | التركيز | المدة |
|---|---|---|---|
| 1 | 1–4 | البوصلة | أسبوعان |
| 2 | 5–10 | الأساس | 3 أسابيع |
| 3 | 11–16 | الإنتاجية | 3 أسابيع |

## 4. بوابات الجودة

| البوابة | السؤال | معيار النجاح |
|---|---|---|
| G0 | هل الرؤية والجمهور واضحان؟ | دستور كتاب معتمد |
| G1 | هل مصفوفة الفصول كاملة؟ | 34 فصلًا بلا فراغ أو تكرار |
| G2 | هل لكل فصل وعد ومخرج؟ | بطاقة فصل مكتملة |
| G3 | هل النموذج التجريبي ناجح؟ | 3 فصول + 8 صفحات + 10 قراء |
| G4 | هل المحتوى دقيق؟ | 100% من الادعاءات موثقة |
| G5 | هل اللغة متسقة؟ | مرور كامل على دليل الأسلوب |
| G6 | هل العناصر البصرية سليمة؟ | تعليق + مصدر + نص بديل لكل عنصر |
| G7 | هل التخطيط سليم؟ | لا قصّ، لا تداخل، لا عناوين يتيمة |
| G8 | هل الكتاب متاح؟ | تباين، نصوص بديلة، EPUB سليم |
| G9 | هل النسخة النهائية جاهزة؟ | بروفة طباعة + PDF + EPUB |

**الحالات:** PASS / FAIL / NOT VERIFIED. لا تُدّعى PASS دون اختبار.

## 5. تعريف «منجز» لكل فصل

الفصل يكون منجزًا فقط عندما:

- [ ] يتبع قالب الفصل.
- [ ] له وعد ومخرج واضح.
- [ ] كل ادعاء له مصدر أو وسم رأي/تجربة.
- [ ] السجل يميز بين `verified` و`partial` و`pending` و`editorial` و`example`؛ لا يبقى ادعاء مؤثر بحالة `pending`.
- [ ] التوصية التحريرية موسومة بوضوح ولا تُعرض كأنها نتيجة دراسة.
- [ ] كل مصطلح جديد مشروح.
- [ ] 2–4 عناصر بصرية على الأقل.
- [ ] كل لقطة مسجلة بتاريخها ومصدرها.
- [ ] المحاكاة الأصلية موسومة بأنها محاكاة ولا تقلد علامة تجارية؛ واللقطة الفعلية تسجل الأداة والإصدار والتاريخ والمصدر والترخيص.
- [ ] كل شكل له تعليق ونص بديل.
- [ ] التمرين له مخرج ومعيار تقييم.
- [ ] مرّ بتحرير تطويري.
- [ ] مرّ بمراجعة تقنية.
- [ ] مرّ بتحرير لغوي.
- [ ] مرّ بفحص تخطيط.
- [ ] حُدّثت حالته في `curriculum-matrix.csv`.

## 8. إيقاع العمل

- **اجتماع أسبوعي:** مراجعة التقدم، العوائق، القرارات.
- **مراجعة دفعة كل 2–3 أسابيع:** بوابة جودة.
- **مراجعة شهرية:** اتساق الصوت، الازدواجية، تغطية النتائج.
- **مراجعة ربع سنوية:** تحديث الأدوات والمصادر.

## 9. إدارة التغيير

- أي فكرة جديدة تُسجل في «قائمة التأجيل»، لا تُضاف فورًا.
- أي تغيير في الهيكل يتطلب تحديث المصفوفة والدستور.
- أي تغيير في التصميم يتطلب تحديث `design-system.md`.
- أي ادعاء جديد يتطلب سجلًا في `fact-check-log.csv`.
- لا يُعاد فتح فصل مكتمل إلا بسبب خطأ موثق.
