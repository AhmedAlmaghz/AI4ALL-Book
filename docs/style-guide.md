# دليل الأسلوب التحريري — Style Guide

## 1. الصوت والنبرة

- **الصوت:** دافئ، واثق، فضولي، عملي، بلا تعالٍ.
- **المخاطبة:** مباشرة بـ«أنت».
- **الضمير:** «نحن» في الرحلات المشتركة، «أنت» في التطبيق.
- **الوعد:** «لنكتشف»، لا «يجب عليك».
- **الصراحة:** «هذا لا يعمل دائمًا»، «هذه ليست نصيحة طبية».
- **الممنوع:** المبالغة التسويقية، التخويف، الوعود المالية، السخرية، الحشو.

## 2. الجمل والفقرات

| القاعدة | المعيار |
|---|---|
| طول الجملة | 10–18 كلمة في المتوسط |
| أقصى جملة | 30 كلمة إلا لضرورة |
| طول الفقرة | 2–5 أسطر في نسخة القراءة |
| أقصى فقرة | 6 أسطر |
| الصوت | مبني للمعلوم غالبًا |
| الأفعال | محددة: «اكتب»، «قارن»، «تحقق»، لا «قم بعملية» |
| الحشو | يُحذف: «في الواقع»، «كما نعلم جميعًا»، «من الجدير بالذكر» |
| التكرار | يُحذف إلا للتثبيت المقصود |

### قبل/بعد
**قبل:** «من الجدير بالذكر أنه يمكن للمستخدم القيام بعملية استخدام أدوات الذكاء الاصطناعي من أجل تحسين الإنتاجية.»

**بعد:** «استخدم الذكاء الاصطناعي لتنجز العمل أسرع. ابدأ بمهمة واحدة متكررة.»

## 3. المصطلحات

- المصطلح العربي أولًا، والإنجليزي بين قوسين عند أول ظهور.
- بعد أول ظهور، يُستخدم العربي وحده.
- لا ترادف غير مبرر: اختر مصطلحًا واحدًا لكل مفهوم.
- المصطلحات التقنية الشائعة تبقى باللاتينية إن كانت أسماء أدوات أو علامات تجارية.
- يُسجّل كل مصطلح في المسرد.

### أمثلة
| المفهوم | العربي | الإنجليزي |
|---|---|---|
| Prompt | طلب | Prompt |
| Context | سياق | Context |
| Hallucination | هلوسة | Hallucination |
| Workflow | سير عمل | Workflow |
| Agent | وكيل | Agent |
| Knowledge base | قاعدة معرفة | Knowledge base |
| Retrieval-Augmented Generation | التوليد المعزز بالاسترجاع | RAG |
| Fine-tuning | ضبط دقيق | Fine-tuning |
| Guardrails | حواجز أمان | Guardrails |
| Human-in-the-loop | الإنسان في الحلقة | Human-in-the-loop |

## 4. العناوين

- عنوان الفصل قصير، جذاب، وواضح: «الكلمة التالية»، «خط أحمر».
- العنوان الفرعي يشرح الفائدة: «كيف يعمل النموذج اللغوي؟»
- عناوين الأقسام تبدأ بفعل أو سؤال: «جرّب الآن»، «كيف تتحقق؟»، «ماذا لو فشل؟»
- لا عناوين غامضة أو شعرية بلا معنى.
- لا عنوان منفرد في أسفل الصفحة.

## 5. الترقيم والتواريخ

- **الأرقام:** غربية (0–9) في كل الكتاب، بما فيها الصفحات، للاتساق مع الواجهات التقنية.
- **التواريخ:** «أكتوبر 2026» بالتقويم الميلادي.
- **الوقت:** «9:00 مساءً» أو «21:00» حسب السياق، بثبات داخل الفصل.
- **النسب:** «40%» بلا مسافة قبل العلامة.
- **المبالغ:** «100 دولار» مع توضيح العملة، لا رموز مبهمة.

## 6. علامات الترقيم

- الفاصلة العربية «،» والمنقوطة «؛» وعلامة الاستفهام «؟».
- علامات التنصيص «» للنقل وال quotations.
- الشرطة القصيرة «–» للمدى، والشرطة «—» للاعتراض.
- الأقواس الغربية () للمصطلحات والاختصارات.
- لا مسافة قبل علامة الترقيم.
- لا تستخدم النقاط الثلاث «...» إلا للحذف الواضح.

## 7. أسماء الأدوات والعلامات التجارية

- تُكتب باللاتينية: ChatGPT، Gemini، Claude، Microsoft Copilot.
- لا تُترجم ولا تُحرّف.
- تُذكر مرة واحدة في العنوان أو أول ظهور، ثم «الأداة» أو «المساعد».
- لا شعارات كبيرة أو مبالغ فيها.
- لا ادعاء رعاية أو شراكة.
- كل لقطة شاشة تُوثّق بتاريخها وإصدارها.

## 8. الاقتباس والإسناد

- كل ادعاء قابل للتحقق له مصدر.
- الإحصاءات: مصدر أولي + تاريخ.
- خصائص الأدوات: مصدر رسمي + تاريخ التحقق.
- الاقتباسات المباشرة بين «» مع اسم المصدر.
- لا اقتباس مُختلق، ولا دراسة مُختلقة، ولا رقم بلا مصدر.
- فصل واضح بين:
  - **حقيقة موثقة:** لها مصدر.
  - **رأي المؤلف:** يُذكر صراحة.
  - **تجربة شخصية:** تُذكر صراحة.

## 9. الإفصاح عن الذكاء الاصطناعي

صفحة في المقدمة توضح:

- أين استُخدم الذكاء الاصطناعي في البحث والتنظيم والتحرير.
- أن كل معلومة خضعت للتحقق البشري.
- أن المسؤولية النهائية للمؤلف.
- أن اللقطات حقيقية أو موصوفة بوضوح إن كانت محاكاة.

### صيغة مقترحة
> استُخدمت أدوات الذكاء الاصطناعي في العصف الذهني، وتنظيم المصادر، وفحص الاتساق، وصياغة بعض النصوص البديلة. لم يُنشر أي ادعاء دون تحقق بشري، وكل الأخطاء المتبقية مسؤولية المؤلف.

## 10. اللغة الشاملة

- لا تفترض جنسًا أو عمرًا أو قدرة أو مستوى تعليميًا.
- استخدم أمثلة من بلدان عربية مختلفة.
- لا تستخدم «المعاق» أو «غير القادر» بوصفها هوية.
- لا تسخر من المبتدئين.
- لا تفترض إنترنت سريعًا أو اشتراكًا مدفوعًا.
- اذكر البدائل المجانية والمنخفضة التكلفة.
- احترم الخصوصية والكرامة في كل مثال.

## 11. التحذيرات

كل تحذير يحتوي:

1. **الخطر:** ماذا قد يحدث؟
2. **لماذا؟** السبب المختصر.
3. **ماذا أفعل؟** إجراء واضح.
4. **متى أتوقف؟** علامة حمراء.

لا تحذير بلا حل، ولا تخويف بلا سبب.

## 12. النصائح

- نصيحة واحدة قابلة للتطبيق.
- من تجربة حقيقية أو مبدأ موثوق.
- قصيرة: 2–4 أسطر.
- لا «حيل» تنتهي صلاحيتها بسرعة.
- لا نصائح تتعارض مع الأمان أو الأخلاق.

## 13. التمارين

كل تمرين يحتوي:

- **الهدف:** ماذا ستتعلم؟
- **الوقت:** 10 / 30 / 60 دقيقة.
- **المدخلات:** ما تحتاجه.
- **الخطوات:** 3–7 خطوات.
- **المخرج:** ما الذي تنتجه؟
- **معيار التقييم:** 4 معايير.
- **التوسيع:** تحدٍ إضافي.
- **تأمل:** سؤال واحد.

## 14. قائمة التحقق قبل اعتماد أي نص

- [ ] الفكرة الرئيسية واحدة وواضحة.
- [ ] كل مصطلح جديد مشروح.
- [ ] لا جملة تتجاوز 30 كلمة بلا ضرورة.
- [ ] لا فقرة تتجاوز 6 أسطر.
- [ ] كل ادعاء له مصدر أو وسم رأي/تجربة.
- [ ] لا وعود مبالغة.
- [ ] التحذيرات تحتوي حلًا.
- [ ] التمرين له مخرج ومعيار.
- [ ] اللغة شاملة ومحترمة.
- [ ] النص يخدم قارئًا غير متخصص.
