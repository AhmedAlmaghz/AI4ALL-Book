## قواعد الملف

- كل فصل في ملف مستقل.
- الاسم: `chNN.md` بأرقام من خانتين.
- كل ملف يبدأ ببيانات YAML مطابقة لـ`templates/chapter-template.md`.
- لا تُكتب تنسيقات محلية داخل النص؛ استخدم عناصر Markdown القياسية.
- كل لقطة تُشار إليها بمعرّف من `docs/screenshot-register.csv`.
- كل ادعاء يُشار إليه بمعرّف من `docs/fact-check-log.csv`.
- لا تُحذف «ملاحظات المؤلف» إلا في نسخة النشر.

## عناصر Markdown المعتمدة

| العنصر | الصيغة |
|---|---|
| صندوق حكاية | `> **حكاية:** …` |
| فكرة كبيرة | `> **الفكرة:** …` |
| تحذير | `> **تحذير:** …` |
| نصيحة | `> **نصيحة:** …` |
| تمرين | `## تمرين التحدي` |
| شكل | `**الشكل 5-1:** …` |
| لقطة | `**اللقطة 5-1:** …` |
| جدول | جدول Markdown قياسي |
| طلب جاهز | كتلة كود `text` |
